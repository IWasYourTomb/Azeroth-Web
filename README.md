🌌 About

Azeroth Website is the official landing page for Azeroth Launcher — a macOS application designed to make managing and launching World of Warcraft game clients easier.

The website combines a modern interface, fantasy-inspired visuals and a responsive design to introduce the launcher, showcase its capabilities and provide access to the latest releases.

Built with Vue 3 and TypeScript.

✨ Features

* Modern Design — A clean interface with fantasy-inspired visual elements.
* Responsive Layout — Optimized for desktop, tablet and mobile devices.
* Dark & Light Themes — Dark, light and system appearance modes.
* Internationalization — Full English and Russian localization.
* Game Expansions — Dedicated sections for supported World of Warcraft expansions.
* Launcher Showcase — Screenshots and detailed feature descriptions.
* Release Integration — Automatically retrieves the latest launcher release from GitHub.
* Release Notes — Displays information about the latest updates.
* SEO Optimized — Open Graph, social previews and search engine metadata.
* Interactive Experience — Smooth animations and carefully designed interactions.

🚀 Getting Started

Prerequisites

* Node.js
* npm
* Git

Installation

Clone the repository:

git clone https://github.com/YOUR_USERNAME/azeroth-website.git

Navigate to the project directory:

cd azeroth-website

Install dependencies:

npm install

Development

Start the development server:

npm run dev

Production Build

Build the application:

npm run build

Preview the production build locally:

npm run preview
